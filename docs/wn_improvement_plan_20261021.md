- 训练图: train_reverse (训练边+反向边)

## 🎯 改进策略（3阶段渐进验证）

4. 保持其他设置不变：
   - 同样的train_reverse图
   - 同样的train_pair_affine归一化
   - 同样的线性分类器
   - 同样的Adam lr=0.05

**验收标准**:
- seed=0完整validation必须≥80.79% (当前80.29% + 0.5pp)

## 📝 实施原则

### 严格的科学规范
1. **一次只改一个变量** - 不同时改文本+分类器+图
2. **validation选择** - 只用validation选模型，test不参与调参
3. **完整保留** - 低分seed也保留，不挑选
4. **证据驱动** - 只实施有上游代码依据的方案
5. **可追溯** - 每个新特征/缓存记录SHA256

### 验收门槛
- 每阶段seed=0 validation至少+0.5pp才进入test
- 未通过则保留参考，不重复test
- 通过后锁定权重，完整test一次
- 达到2pp目标后才进入10 seeds

### 失败预案
如果3个阶段都未达到2pp:
1. 保留全部失败证据和训练日志
2. 如实报告：当前工程方案存在3.84pp gap
3. 标记为"需要作者原始代码确认"
4. 不伪造、不挑seed、不缩减测试集
